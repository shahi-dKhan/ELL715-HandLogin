Each pixel within the silhouette tunnel is represented by a 14-dimensional feature vector:

\[
\mathbf{f} =
\begin{bmatrix}
x,\, y,\, t,\, z,\,
d_E,\, d_W,\, d_N,\, d_S,\,
d_{NE},\, d_{NW},\, d_{SE},\, d_{SW},\,
dT^{+},\, dT^{-}
\end{bmatrix}^{T}
\]

where:
\begin{itemize}
    \item $x, y, t$ denote the spatial and temporal coordinates of the pixel,  
    \item $z$ is the depth value,  
    \item $d_{E}, d_{W}, d_{N}, d_{S}, d_{NE}, d_{NW}, d_{SE}, d_{SW}$ represent directional distances from the pixel to the nearest background boundary in the eight cardinal directions, and  
    \item $dT^{+}, dT^{-}$ denote the forward and backward temporal persistence of the silhouette pixel across time.  
\end{itemize}

Directional distances and temporal runs are efficiently computed using Numba-accelerated kernels for parallel processing.

All feature vectors from the sequence are collected into a feature matrix:

\[
\mathbf{F} =
\begin{bmatrix}
\mathbf{f}_1 & \mathbf{f}_2 & \dots & \mathbf{f}_N
\end{bmatrix}
\in \mathbb{R}^{14 \times N}
\]

and are normalized feature-wise to the range $[0, 1]$ as:

\[
\mathbf{F}_{\text{norm}} = \frac{\mathbf{F} - \mathbf{F}_{\min}}{\mathbf{F}_{\max} - \mathbf{F}_{\min} + \epsilon}
\]

where $\epsilon$ is a small constant (e.g., $10^{-6}$) to avoid division by zero.


\subsection{Extraction of Covariance Matrix}
The silhouette tunnel provides us with a rich representation of the pixel features over time. To analyze the variability and relationships between these features, we compute the covariance matrix of the normalized feature matrix:

\[
\mathbf{C} = \frac{1}{N-1} \mathbf{F}_{\text{norm}} \mathbf{F}_{\text{norm}}^{T}
\]

where $\mathbf{C} \in \mathbb{R}^{14 \times 14}$ is the covariance matrix capturing the pairwise feature correlations across all pixels in the silhouette tunnel across all the frames.



\text{\textbf{Note: }} In the paper, the denominator of the above equation is given as $N$. However, to obtain an unbiased estimate of the covariance, we use $N-1$ in our implementation.

We then just take the upper triangular part of the covariance matrix (including the diagonal) and vectorize it to form our final feature descriptor for the video sequence:

\[
\mathbf{d} = \text{vec}(\mathbf{C}_{\text{upper}})
\]

where $\mathbf{d} \in \mathbb{R}^{105}$ is the final feature descriptor capturing the relationships between the pixel features over time.



\subsection{Temporal Hierarchical Covariance Descriptor}

To capture the temporal dynamics of each gesture, the feature matrix $F \in \mathbb{R}^{14 \times N}$ is divided into multiple temporal segments. 
We use a three-level hierarchy where the sequence is split into $1 + 2 + 4 = 7$ parts in total, giving both coarse and fine temporal resolution.

For each segment, a covariance matrix is computed as:
\[
C = \frac{1}{N - 1} \sum_{n=1}^{N} (f_n - \mu)(f_n - \mu)^{\top},
\quad \text{where} \quad
\mu = \frac{1}{N} \sum_{n=1}^{N} f_n
\]
Each $C$ is symmetric, so we only keep its upper-triangular entries (105 values for $14$ features). 
The seven such vectors are then concatenated to form the final descriptor:
\[
\text{Descriptor}_{TH} = [C_1^{ut}, C_2^{ut}, \ldots, C_7^{ut}] \in \mathbb{R}^{735}
\]

This representation captures how feature correlations evolve over time while remaining compact. 
\textbf{Implementation Note: } all covariance computations are parallelized using Numba for efficiency.\\

\subsection{Hand-Morphology:}

For each sub-silhouette, a separate feature matrix $F_k \in \mathbb{R}^{14 \times N_k}$ is computed, following the same 14-dimensional feature representation used for the full silhouette.  
Each sub-silhouette then produces its own temporal-hierarchical covariance descriptor $C_k \in \mathbb{R}^{735}$.

The final multichannel descriptor is formed by concatenating the descriptor of the full silhouette with those of the $K=3$ sub-silhouettes:
\[
\text{Descriptor}_{multi} = [\, C_{\text{full}},\, C_1,\, C_2,\, C_3 \,]
\]

This results in a combined representation of dimension:
\[
4 \times 735 = 2940
\]

\subsubsection{Comparison of Inter-Gesture and Intra-Gesture Mappings:}
%@ copilot, you can make three figures side by side for the three variants: Baseline, Temporal Hierarchy and Hand Morphology
\textbf{Intra-Gesture Matching:} This involves comparing samples of the same gesture type to evaluate consistency within that gesture. For example, comparing different instances of the "Compass" gesture to see how similar they are to each other.\\
\textbf{Inter-Gesture Matching:} This involves comparing samples of different gesture types to assess how distinct each gesture is from the others. For example, comparing "Compass" gestures against "Piano" gestures to evaluate their separability.\\
\textbf{EER Matrices:} The matrix consists of EER values where each entry $(i, j)$ represents the EER when comparing gesture type $i$ against gesture type $j$. The diagonal entries represent intra-gesture EERs (same gesture comparisons), while the off-diagonal entries represent inter-gesture EERs (different gesture comparisons).\\

To analyze the influence of gesture type on authentication performance, both \textbf{intra-gesture} and \textbf{inter-gesture} evaluations were conducted.
Let $G_i$ denote a \textit{gallery gesture} and $G_j$ denote a \textit{probe gesture}, where $i, j \in \{1, 2, 3, 4\}$ correspond to the gestures \{Compass, Piano, Push, UCDO\}.

\noindent
The evaluation protocol proceeds as follows:

\begin{enumerate}[label=\textbf{Step \arabic*:}]
    \item \textbf{Gallery Construction:} For each gesture $G_i$, a gallery template is created for every enrolled subject ($s_g \in \{01,\dots,08\}$) by averaging the descriptors of all available trials:
    \[
        \mathbf{D}^{(i)}_{\text{gallery}, s_g} = \frac{1}{N_i} \sum_{k=1}^{N_i} \mathbf{d}^{(i,k)}_{s_g}
    \]
    where $\mathbf{d}^{(i,k)}_{s_g}$ represents the $k$-th descriptor for gesture $G_i$ of subject $s_g$. Note that this is different from the protocol followed above, where only one sample was used at a time for gallery, and all the combinations were considered while computing genuine and impostor scores. 

    \item \textbf{Probe Samples:} Probe samples are taken from subjects $s_p \in \{09,\dots,16\}$ performing gesture $G_j$. Each probe descriptor is denoted $\mathbf{d}^{(j,m)}_{s_p}$.

    \item \textbf{Score Computation:} For every gallery–probe pair, the cosine similarity is computed as:
    \[
        \text{sim}\left(\mathbf{D}^{(i)}_{\text{gallery}, s_g}, \mathbf{d}^{(j,m)}_{s_p}\right)
        = 1 - \text{cosine\_distance}\left(\mathbf{D}^{(i)}_{\text{gallery}, s_g}, \mathbf{d}^{(j,m)}_{s_p}\right)
    \]
    Genuine and impostor scores are defined as:
    \[
        \begin{cases}
        s_g = s_p, & \text{Genuine scores (same subject)}\\
        s_g \neq s_p, & \text{Impostor scores (different subjects)}
        \end{cases}
    \]

    \item \textbf{EER Computation:} For each gesture pair $(G_i, G_j)$, the Equal Error Rate (EER) is computed from the genuine and impostor score distributions.
    \begin{itemize}
        \item $i = j$: \textit{Intra-gesture EER} — same gesture for gallery and probe.
        \item $i \neq j$: \textit{Inter-gesture EER} — different gestures for gallery and probe.
    \end{itemize}

    \item \textbf{Gesture EER Matrix:} The process yields a $4 \times 4$ EER matrix:
    \[
        \text{EER}_{i,j} = f(G_i, G_j)
    \]
    where diagonal elements ($i=j$) represent intra-gesture performance, and off-diagonal elements ($i \neq j$) measure inter-gesture confusion.

\end{enumerate}


\noindent
Several patterns, trennds and observations that appear from the aove results are:

\vspace{4pt}
\noindent
\textbf{1. Same-gesture matching is better.} \\
Diagonal entries of the EER matrices (intra-gesture) are substantially lower than the off-diagonal ones. 
This indicates that when the same gesture is used during both enrollment and testing, authentication accuracy is high. 
In contrast, cross-gesture (inter-gesture) matching produces significantly higher EERs, confirming that the descriptors are strongly gesture-sensitive.

\vspace{4pt}
\noindent
\textbf{2. Hand morphology improves performance.} \\
The inclusion of sub-silhouette tunnels (morphological features) provides the largest reduction in diagonal EERs for certain gestures—particularly \textit{Compass} and \textit{UCDO}. 
This suggests that morphology-based cues (hand shape and structural consistency) add stability and complement the temporal-motion information in the descriptor.

\vspace{4pt}
\noindent
\textbf{3. Temporal hierarchy gives modest gains.} \\
Dividing a gesture into temporal segments captures the dynamic structure of motion and yields small improvements in some gestures. 
However, the overall effect is less pronounced than the morphology-based approach, indicating that temporal segmentation alone cannot fully model gesture variability.

\vspace{4pt}
\noindent
\textbf{4. Inter-gesture confusion remains high.} \\
Off-diagonal EER values remain elevated across all variants. 
This indicates that descriptors trained for one gesture do not generalize well to other gestures. 
In other words, the system is not gesture-agnostic and relies on users performing the same gesture during both enrollment and authentication.


\textbf{It is also observed that Compass and UCDO gestures perform better than Piano and Push gestures.} This could be due to the distinct hand shapes and motion patterns involved in Compass and UCDO, which are better captured by the morphology features. In contrast, Piano and Push gestures may involve more subtle or similar hand configurations, leading to higher confusion rates. \\


\noindent
\textbf{Will this system work for random hand gestures?} \\
\textit{Not really.} The observed results indicate that the descriptors we are using are gesture-dependent and requires consistent gestures for authentication. This will be further proved in an experiment which is mentioned next. But the current results indicate:


\begin{itemize}
    \item \textbf{Gesture dependency:} The feature representation includes spatial coordinates $(x, y, t)$, depth, and temporal run-lengths. These are strongly tied to the motion and dynamics of specific gestures. Random gestures will produce different patterns that do not match enrolled templates.
    \item \textbf{High inter-gesture EERs:} The elevated off-diagonal EERs ($0.35$–$0.50$ range) confirm that cross-gesture matching yields poor authentication accuracy.
\end{itemize}

\subsection{Experiment 2: Multi-Gesture Enrollment Authentication}

\subsubsection*{Objective}
We try to analyze if a multi-gesture enrollment strategy can
improve performance compared to single-gesture enrollment. \\
Instead of enrolling each user with a single gesture, we construct a universal
gallery template by averaging feature descriptors from multiple gestures performed by
the gallery subjects. Probe samples are then drawn from all gestures of probe subjects.

\subsubsection*{Methodology}
For each variant (\textit{Baseline}, \textit{Temporal Hierarchy}, and \textit{Hand Morphology}),
the following protocol was used:
\begin{enumerate}
    \item Average all descriptors from all gallery subjects (\(1 \text{–} 8\)) across all gestures.
    \item A \textbf{universal gallery template} formed by averaging all gallery descriptors:
    \[
        \bar{C}_{gallery} = \frac{1}{N_G} \sum_{i=1}^{N_G} C_i
    \]
    where \(C_i\) represents the descriptor vector from the $i$-th gallery sample.
    \item Each probe descriptor from probe subjects (\(9 \text{–} 16\)) was compared against
          the universal template using cosine similarity.
    \item Genuine scores were obtained from gallery descriptors (same population as enrolled users),
          while impostor scores were obtained from probe descriptors (unseen subjects).
    \item The Equal Error Rate (EER) was computed from the two distributions.
\end{enumerate}

\section*{Part-2: Improvement}
\label{sec:part2_improvement}
The original paper demonstrates that silhouette and depth features combined with temporal modeling produce strong authentication performance. However, when covariance-like descriptors or multichannel descriptors are computed over high-dimensional feature spaces: (i) covariance estimation becomes unstable for short temporal segments, and (ii) many descriptor dimensions are noisy or redundant — both reduce verification accuracy and increase computation time \cite{Wu2015}. 

\subsection*{1. Identification of research gap }
\label{sec:gap}
The specific gap we address is two-fold:
\begin{enumerate}
  \item \textbf{Unstable covariance estimation for short segments:} when temporal hierarchy divides sequences into small segments, empirical covariance estimates are poorly conditioned (near-singular) and regularization (e.g., Ledoit–Wolf) is effective but computationally heavy for many segments.
  \item \textbf{Redundancy and high dimensionality of descriptors:} concatenated multi-scale (sub-tunnel) descriptors produce large vectors with redundant directions. Such dimensions introduce noise that reduces discriminability under cosine similarity.
\end{enumerate}
Both issues are particularly relevant in the context of the hand-gesture authentication pipeline of Wu et al. (2015), where temporal hierarchical covariance descriptors and sub-silhouette channels are central elements. This motivates a solution that is both \emph{fast} and \emph{discriminative}.

\subsection*{2. Proposed solution}
\label{sec:proposal}
We propose a three-step improvement:
\begin{enumerate}
  \item \textbf{Fast adaptive shrinkage covariance estimator:} replace repeated Ledoit–Wolf fits with an analytic shrinkage rule blending sample covariance $S$ with a scaled identity:
  \[
  S_{\text{shrunk}} = (1-\alpha) S + \alpha \mu I, \quad 
  \mu = \frac{\mathrm{tr}(S)}{D}, \quad
  \alpha = \min\left(0.5, \frac{D}{N+D}\right),
  \]
  giving conditioning benefits with lower runtime.
  \item \textbf{PCA whitening (global) + LDA (supervised):} 
    \begin{enumerate}
      \item Apply PCA to remove noisy, low-variance directions and reduce descriptor dimensionality:
      \[
      X_{\text{PCA}} = U^\top (X - \bar{X}),
      \]
      where $U$ contains top eigenvectors of the covariance of gallery descriptors.
      \item Apply LDA to maximize between-class separability:
      \[
      W_{\text{LDA}} = \arg\max_W \frac{|W^\top S_B W|}{|W^\top S_W W|},
      \]
      where $S_B$ is between-class scatter and $S_W$ is within-class scatter.
    \end{enumerate}
    Use cosine similarity in the LDA space for verification.
  \item \textbf{Caching + grid search:} cache per-sample descriptors to avoid recomputation and allow exhaustive search over PCA components and temporal hierarchy levels.
\end{enumerate}

\paragraph{Rationale:} PCA reduces noise and stabilizes covariance inversion; LDA explicitly maximizes between-class variance, improving verification separability \cite{Belhumeur1997}.

\label{sec:implementation}

\paragraph{Grid search:}

  \item PCA components: \{20, 30, 40, 50, 60\}  
  \item Temporal hierarchy levels: \{2, 3, 4\}

\paragraph{Mathematical justification:}
\begin{itemize}
  \item Let $\mathbf{x}_i \in \mathbb{R}^D$ be the descriptor for frame $i$. The hierarchical covariance descriptor is
  \[
  C = \bigoplus_{\text{segments}} \text{cov}(\mathbf{x}_i),
  \]
  where $\bigoplus$ denotes concatenation over temporal segments.  
  Fast shrinkage replaces $\text{cov}(\mathbf{x}_i)$ with a well-conditioned $S_{\text{shrunk}}$.
  \item PCA reduces dimensionality and projects descriptors onto principal axes:
  \[
  X_{\text{PCA}} = U^\top (X - \bar{X})
  \]
  discarding directions with small eigenvalues (noise reduction).
  \item LDA maximizes class separability:
  \[
  W_{\text{LDA}} = \arg\max_W \frac{|W^\top S_B W|}{|W^\top S_W W|},
  \]
  providing discriminative features for cosine similarity matching.
\end{itemize}

\paragraph{Runtime:} Descriptor caching ensures that PCA + LDA evaluation takes seconds; covariance assembly with fast shrinkage scales as $\mathcal{O}(D^2 N)$ per segment, substantially faster than Ledoit–Wolf fits.

\subsection*{5. Discussion and limitations}
\begin{itemize}
  \item PCA+LDA effectively removes noise and aligns descriptors along discriminative axes.  
  \item Overfitting risk is mitigated via PCA preprocessing and held-out probe evaluation.  
  \item Method is dataset-dependent but computationally efficient and generalizable to other silhouette/depth gesture datasets.
\end{itemize}
